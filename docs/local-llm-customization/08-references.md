# 参考リンク

この章では、軽量ローカルLLMのカスタマイズを学ぶときに参照しやすい公式ドキュメントをまとめます。

- [Ollama Documentation](https://docs.ollama.com/)
- [llama.cpp GitHub](https://github.com/ggml-org/llama.cpp)

- [Hugging Face Transformers Quantization](https://huggingface.co/docs/transformers/quantization/bitsandbytes)

## 読み方

最初からすべてを読む必要はありません。

ローカルで動かす段階ではOllamaやllama.cppを見ます。資料検索を作り始めたらLlamaIndex、LangChain、Chromaを見ます。LoRAやQLoRAを試したくなったらPEFT、TRL、Axolotlを参照するとよいです。
